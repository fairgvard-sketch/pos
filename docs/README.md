# Документация Kassa

Kassa — часть ANGLE: POS, публичные Menu / Orders / Reserve, общий Supabase
и Android. Сайт и кабинет владельца находятся в соседнем `../anglesite`.

Навигация пересмотрена 13.09.2026. Это дата систематизации, не дата повторной
проверки каждой функции или production-среды.

В больших справочниках есть поэтапные дополнения. Номер миграции в заголовке
раздела — происхождение изменения, не достаточная версия для выпуска.
Основной источник поведения — текущий код и последнее определение RPC.
При изменении модуля сверять и обновлять соответствующий раздел; оставшиеся
исторические формулировки не считать новыми подтверждёнными дефектами.
